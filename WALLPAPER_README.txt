Dépose ici ton image de fond d'écran sous le nom exact "wallpaper.jpg"
(ou renomme le fichier correspondant dans public/ si tu préfères un .png,
et adapte alors l'extension dans src/components/os.css, propriété
`background-image` de la classe `.os-desktop`).

Tant qu'aucune image n'est présente, le bureau garde son dégradé sombre
par défaut — rien ne casse si tu ne mets rien ici.

Conseil : une image assez sombre ou contrastée fonctionne mieux, un léger
voile noir est déjà appliqué par-dessus pour garder les icônes lisibles.
